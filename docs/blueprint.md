# **App Name**: SpaceSense AI

## Core Features:

- Session Creation: Allow designers to create sessions by providing room dimensions and themes (overall and per wall).
- Session Listing: Enable users to view a list of their created sessions for easy access and management.
- Session Loading: Enable users to load existing design sessions to continue working on them or review past designs.
- AI Image Generation: Integrate generative AI tool that can create realistic images from textual descriptions for the wall section of a house
- Session Export: Provide an option for users to export their session data as a JSON file for sharing or backup purposes.
- Authentication: Implement secure user authentication to scope sessions per user.

## Style Guidelines:

- Primary color: Soft, muted blue (#A0D2EB) to evoke a sense of calm and spaciousness.
- Background color: Light, off-white (#F5F5F5) to provide a clean and neutral backdrop.
- Accent color: Warm, desaturated orange (#E5B784) to highlight interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, offering a modern, machined, objective, neutral look.
- Maintain a clean, minimalist layout with ample white space to emphasize the visual design elements.
- Use simple, outlined icons to represent various actions and elements, ensuring clarity and usability.
